# KIS 시세 데이터 권한 확인

## 확인된 공식 안내

한국투자증권 KIS Developers의 [Open API 서비스 소개](https://apiportal.koreainvestment.com/about-open-api)는 시세정보를 계좌를 보유한 개인 고객이 자기 자산의 투자 목적으로 이용할 수 있고, 제3자 제공은 불가하다고 안내합니다. [서비스 이용안내](https://apiportal.koreainvestment.com/about-howto)는 개인 고객이 본인 자산으로 자기 전략을 매매하는 용도의 이용 절차를 설명합니다.

공개 안내에는 로컬 보관 기간, 백테스트와 모델 학습의 세부 조건이 모두 명시되어 있지 않습니다. 사용자는 2026-11-07 대화에서 KIS의 서면 답변으로 **로컬 저장, 백테스트, 본인 계좌용 모델 학습이 모두 허용됨을 확인했다**고 전달했습니다. 이 기록은 사용자가 전달한 확인 결과를 반영하며, KIS 답변 원문이나 문의 번호는 저장소에 포함하지 않습니다.

## KIS에 확인할 항목

문의 시 개인 본인 계좌, 본인 투자, 로컬 Windows PC/PostgreSQL, 외부 공개·제3자 제공 없음, KIS Open API로 수신한 국내·미국 시세라는 사용 범위를 구체적으로 설명하고 답변을 보관합니다.

1. API로 받은 실시간·과거 시세와 호가를 본인 PC의 PostgreSQL에 저장할 수 있나요? 허용되는 보관 기간과 삭제 조건은 무엇인가요?
2. 이렇게 저장한 자료를 본인 계좌의 매매 전략을 검증하는 과거 백테스트에 사용할 수 있나요?
3. 같은 자료로 본인 계좌 전용 LightGBM/XGBoost 모델을 학습하고, 모델 파일을 로컬 PC에 보관할 수 있나요?
4. 거래소별 데이터 라이선스나 별도 신청·요금·표시 제한이 적용되나요? PAPER와 REAL 자격정보로 받은 시세에 차이가 있나요?
5. 로컬 전용 대시보드에서 본인만 시세와 분석 결과를 보는 것이 제3자 제공에 해당하지 않는지, 모델 가중치·요약 지표를 외부에 전송하지 않는 경우 별도 조건이 있는지 확인해 주세요.

답변 날짜, 담당 부서, 문의 번호, 허용된 시장·엔드포인트·보관 기간·목적을 기록합니다. 답변이 일반적이거나 모호하면 해당 사용 권한은 계속 미확인으로 둡니다.

## 프로젝트 적용

- 사용자가 공유한 KIS 공지에 따라 국내주식 종목분석 API 7종(대차대조표, 손익계산서, 재무비율, 수익성·기타주요·안정성·성장성 비율)은 2026-11-11 장 종료 후 16:00부터 호출이 차단될 예정입니다. 현재 저장소 코드에서 해당 API 명칭을 검색했을 때 사용 흔적은 없었으며, 프로젝트는 시세·계좌·주문 API를 사용합니다. 이후 종목분석 API를 추가할 경우 종료 대상 API는 사용하지 않고 별도 권리 확인된 데이터 출처를 검토합니다.
- KIS 시세의 로컬 캡처는 사용자의 개인 계좌 운용 범위에서만 실행하고 외부로 전송하거나 공개하지 않습니다.
- 2026-11-06 Windows 로컬 점검에서 `.env_local`의 `SERVER_ADDRESS=127.0.0.1`, 실행 중인 Spring `8080` 및 Python `8000` 리스너가 모두 loopback으로 확인됐습니다. Python Uvicorn과 Next.js dashboard도 `127.0.0.1`에 바인딩합니다. `.env_local`은 Git ignore 대상입니다.
- 사용자가 전달한 KIS 서면 확인 범위에 따라 로컬 저장, 백테스트, 본인 계좌용 모델 학습을 허용합니다. 사용 목적은 개인 운용에 한정하며, 공개·제3자 제공은 허용하지 않습니다.
- KIS 출처만 포함된 PostgreSQL 내보내기는 확인된 권한 범위와 개인 사용 제한을 CSV SHA-256에 묶은 provenance sidecar로 기록합니다. 백테스트와 학습기는 파일 해시와 목적별 권한을 계속 검증합니다. KIS 시세 외 다른 공급자의 자료가 섞이면 해당 sidecar는 검토 대기로 유지하고 그 공급자의 권리를 별도로 확인해야 합니다.
- 확인 일자, 문의 번호, KIS의 원문, 세부 보관 기간과 API별 조건은 저장소에 기록되지 않았습니다. 허용 범위가 추가되거나 달라질 때에는 provenance 기록을 갱신하고, 보관 기간이나 특정 API·시장에 대한 조건이 불명확하면 그 조건에 해당하는 사용은 추가 확인 전까지 보류합니다.
- 계좌번호, App Key, App Secret, 액세스 토큰, 원시 KIS 응답은 권리 검토 기록이나 Git에 넣지 않습니다.

이 확인 절차는 데이터 약관의 법적 해석을 제공하지 않습니다. 모호한 조건은 KIS에 서면으로 재확인합니다.
