# AI Stock Trader v1.0 Roadmap

## 방향

AI와 퀀트 전략 결합형 국내·미국 당일매매 시스템입니다. 기본 증권사는 KIS Open API입니다. NautilusTrader와 강화학습은 사용하지 않습니다.

초기 운영 한도(종목당 자산 10%, 거래당 0.25%, 일일 손실 1%, 최대 3종목, 연속 손절 3회)는 전략 검증용 시작값이며 수익 보장이나 최적값이 아닙니다. 설정값으로 관리하고, 고정 상수로 매매 판단에 박아 넣지 않습니다.

## 단계와 통과 기준

1. **P1 — KIS 연결 기반:** 별도 paper/real 인증, 국내·미국 잔고·주문가능 금액, WebSocket·호출 제한·마스킹. Mock과 paper 통합 조회를 검증하며 주문은 비활성화.
2. **P2 — 주문 엔진:** 매수·매도·정정·취소, 부분체결·중복 차단·재시작 복구. 모의 전 과정과 장애 시나리오를 통과.
3. **P3 — 퀀트:** VWAP, ORB, EMA, ATR, 유동성, 비용 모델. 과거 데이터 결과 재현과 미래 데이터 누수 방지.
4. **P4 — AI:** LightGBM/XGBoost, 피처·모델 버전·실시간 추론. 미사용 데이터에서 퀀트 대비 성능 비교.
5. **P5 — 자동 모의운영:** 국내·미국 시장 세션, 장 마감 관리, 장애 시나리오. 연속 모의 세션에서 안정성 확인.
6. **P6 — 실전 전환:** 최소 수량, 가격·비용·손익 대조, 손절·익절과 운영 중지. 별도 승인 후 제한된 주문만 켭니다.
7. **P7 — 성과 개선:** 시장별 모델, 종목 선택, 보고서, 재학습·롤백·운영 감시.

## 구현 현황 (2026-11-05)

1. **P1:** Spring REST 읽기 전용 계좌·잔고 기반과 Python REST/WebSocket 시세 연결을 구현했습니다. Mock 테스트는 통과했지만 paper 계좌 키가 로컬에 없어 KIS 국내·미국 계좌 스모크 테스트는 미완료이며 P1 완료로 간주하지 않습니다. WebSocket과 계좌 조회는 기본 잠금입니다.
2. **P2:** PostgreSQL 기반 paper 주문, 부분체결, 체결 중복 키, 포지션·현금 정산, 취소·만료와 기본 한도 검증이 있습니다. PostgreSQL 장애·재시작 복구 통합 시나리오를 추가 검증해야 합니다.
3. **P3:** 단일 세션 ORB/VWAP/EMA/ATR 롱 전략과 상대거래량·스프레드·거래대금 필터, 다음 봉 진입, 비용·슬리피지 및 보수적 스톱 체결을 구현했습니다. 현재 개발 데이터에 대한 성능 주장 없이, 실제 데이터 기반 재현 테스트가 남아 있습니다.
4. **P4:** LightGBM/XGBoost 학습 파이프라인, 날짜 순서 데이터 분리, 피처/레이블 생성, 모델 해시·메타데이터 등록과 비실행 추론 미리보기를 구현했습니다. 실제 시장 데이터 학습·퀀트 성능 비교와 모델 승인 정책 검증은 남아 있습니다.
5. **P5:** KRX/NYSE 거래소 세션 달력, 분 단위 거래틱→봉 집계, 시세 지연/AI/브로커 상태 및 손실·포지션·장마감 기반 진입 차단기를 추가했습니다. opt-in WebSocket 세션 모니터는 재연결과 분봉 수집을 지원하지만 주문은 만들지 않습니다. 자동 신호·위험 게이트·paper 체결의 연결, 재시작 복구, 연속 세션 검증은 남아 있습니다.
6. **P6–P7:** 후속 단계입니다.

이 단계별 상태는 코드 검증과 실제 KIS 계정 검증을 분리해 기록합니다. 계좌 키 없이 Mock 테스트는 통과하지만, 이는 실제 KIS 연결 성공을 뜻하지 않습니다.
